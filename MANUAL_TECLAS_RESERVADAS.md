# Manual de teclas reservadas — DualQueue Player

Este manual descreve as teclas que já possuem uma função operacional no aplicativo. Elas não podem ser atribuídas como atalhos personalizados de pads.

## Regras gerais

- O aplicativo precisa estar em foco para receber atalhos.
- Atalhos ficam suspensos enquanto um campo de texto ou o campo de captura de atalho está em edição.
- `Esc` cancela a captura de um atalho; ele não é salvo como atalho de pad.
- Atalhos com `Command`, `Control` ou `Option` não podem ser cadastrados.
- O atalho personalizado deve ser uma tecla livre. O aplicativo informa quando a tecla escolhida é reservada.

## Teclas reservadas no modo Player

| Tecla | Função |
| --- | --- |
| `Space` | Play/Pause da playlist |
| `Esc` | Para a playlist |
| `A` | Seleciona a Queue A |
| `B` | Seleciona a Queue B |
| `←` | Seleciona a faixa anterior |
| `→` | Seleciona a próxima faixa |
| `1` | Aciona o Pad 1 da página atual |
| `2` | Aciona o Pad 2 da página atual |
| `3` | Aciona o Pad 3 da página atual |
| `4` | Aciona o Pad 4 da página atual |
| `5` | Aciona o Pad 5 da página atual |
| `6` | Aciona o Pad 6 da página atual |
| `7` | Aciona o Pad 7 da página atual |
| `8` | Aciona o Pad 8 da página atual |
| `9` | Aciona o Pad 9 da página atual |
| `0` | Aciona o Pad 10 da página atual |

## Teclas reservadas no modo Performance

| Tecla | Função |
| --- | --- |
| `P` | Play/Pause da operação de Performance |
| `Shift+P` | Para todos os cues |
| `Space` | Pausa ou retoma os cues ativos |
| `Esc` | Para todos os cues |
| `←` | Move a seleção para o cue anterior |
| `→` | Move a seleção para o próximo cue |

As teclas `A`, `B` e `1`–`0` continuam reservadas globalmente para manter o mesmo comportamento quando o usuário volta ao modo Player.

## Atalhos de menu do aplicativo

Estes atalhos também são reservados pelo macOS e pelos menus do aplicativo:

| Tecla | Função |
| --- | --- |
| `Command+N` | Novo projeto |
| `Command+O` | Abrir projeto |
| `Command+S` | Salvar projeto |
| `Command+Shift+S` | Salvar projeto como |

## Exemplos de teclas livres

Desde que não estejam em uso por outro recurso, teclas como `C`, `D`, `E`, `F`, `G`, `H`, `J`, `K`, `L`, `M`, `Q`, `R`, `T`, `U`, `V`, `W`, `X`, `Y` e `Z` podem ser usadas para pads. Também é possível usar combinações `Shift+tecla` livres.

Cada pad deve ter um arquivo de áudio configurado em **Escolher…** para que o atalho produza som.
